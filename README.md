# Focusmart

## Overview

The app's purpose is to build analytics for Google Chrome usage and help users boost productivity by helping them control the distractions. 
This is to be done by mainly blocking websites but also building goals for the websites as well.

## Features

- ### Grayscaling Websites
  We will have the option of grayscaling the websites except for the websites configured to not be grayscaled by the user, there will be a grayscale button that can be turned off to introduce colors to all the websites as well.

- ### Blocking Websites
  Having customizations in blocking websites like time limits for certain websites, and complete blocking for others.

- ### Website Analytics
  We will track the website usage and create weekly reports that will be emailed to the user showcasing their average screen time for each website, we will also categorize the websites using AI
  and build a productivity score with the insights showing where the user can improve and helping out with some strategies of that. We can integrate AI by creating
  an MCP servers which can give it access to make time limits and blocking websites and suggest those to the user to implement.
